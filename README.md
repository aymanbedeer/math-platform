# خوارزميات البسيوني في الرياضيات

منصة ويب لمعلم رياضيات واحد: حسابات للطلاب ينشئها المعلم، ودروس لكل صف، واشتراك شهري يتوقف تلقائيًا بعد فترة السماح، ولوحة تحكم للمعلم.

## التقنيات

- Next.js 15 (App Router) و TypeScript و Tailwind، بالعربية من اليمين لليسار.
- PostgreSQL عبر Drizzle ORM (في الإنتاج: Supabase المجانية).
- ملفات PDF في مجلد `uploads` محليًا، أو في Supabase Storage في الإنتاج (`STORAGE_DRIVER=supabase`).
- الفيديو: YouTube «غير مُدرج» مع علامة مائية متحركة فوق المشغّل.
- كلمات المرور: PBKDF2 عبر Web Crypto، والجلسات محفوظة في قاعدة البيانات.

## التشغيل محليًا

```bash
cp .env.example .env.local     # ثم عدّل DATABASE_URL و APP_SECRET
npm install
npm run db:migrate
TEACHER_PASSWORD=كلمة-سر-قوية npm run db:seed          # أو أضف --demo لبيانات تجريبية
npm run dev
```

اختبارات منطق الاشتراك: `npm test`

## قواعد الاشتراك

- الحالة تُحسب عند كل طلب من تاريخ الانتهاء، فلا حاجة لمهمة مجدولة:
  مفعّل حتى تاريخ الانتهاء، ثم «فترة سماح» لعدد الأيام في الإعدادات، ثم «موقوف».
- تسجيل دفع وهو مفعّل أو في السماح: يُمدّ الاشتراك من تاريخ الانتهاء السابق (أيام السماح محسوبة عليه).
- تسجيل دفع وهو موقوف أو لم يدفع من قبل: يبدأ الاشتراك من اليوم.
- الإيقاف اليدوي والإعفاء يتجاوزان التاريخ. كل دفع وإيقاف وتفعيل وتمديد يُحفظ في سجل الحساب.
- الدروس «المجانية» تبقى مفتوحة للحساب الموقوف.

## الحماية

- حد الأجهزة (افتراضيًا 2): الدخول من جهاز ثالث يُغلق أقدم جلسة.
- 5 محاولات خاطئة توقف الدخول لهذا الحساب 15 دقيقة.
- ملفات PDF تُعرض صفحةً صفحة على canvas مع اسم الطالب فوقها، ورابط الملف موقّع ومرتبط بالطالب وينتهي بعد 10 دقائق.
- التحميل مسموح فقط للملفات التي يحددها المعلم.

## حدود معروفة

- رابط YouTube غير المُدرج يمكن نسخه ومشاركته. للحماية الحقيقية: Bunny Stream لاحقًا (تغيير `video-player.tsx`).
- ملفات PowerPoint لا تُحوَّل تلقائيًا: يحفظها المعلم كـ PDF ثم يرفعها.
- أرقام واتساب المحلية التي تبدأ بـ 0 تُحوَّل لمفتاح مصر (+20) في `src/components/ui.tsx`.
